# StudyHelper 产品待办列表

## MVP 定义

**核心链路：拍照 → AI 识别题目 → 苏格拉底式引导答疑 → 反馈互动**

MVP 只做这一条链路，跑通后再叠加数据沉淀和练习模块。

---

## Epic 1: AI 编排层搭建 (P0)

> 目标：本地部署 Dify，跑通"图片识别 → 知识点提取 → 苏格拉底解答"工作流

| Story | 描述 | 优先级 | 状态 |
|-------|------|--------|------|
| 1.1 | 本地 Docker 部署 Dify 开源版，验证管理后台可访问 | P0 | 📋 |
| 1.2 | 在 Dify 中配置大模型凭证（至少一个多模态模型 + 一个文本推理模型） | P0 | 📋 |
| 1.3 | 构建"题目识别"工作流节点：上传图片 → 输出题干文本 + 学科分类 | P0 | 📋 |
| 1.4 | 构建"知识点提取"工作流节点：基于题干输出二级知识点标签（如：初中数学-勾股定理） | P0 | 📋 |
| 1.5 | 构建"苏格拉底解答"工作流节点：严格不直接给答案，先给出解题思路和第一步引导 | P0 | 📋 |
| 1.6 | 串联完整 Chatflow（识别→提取→解答），约束输出格式：Markdown + LaTeX + 尾部 JSON 标签 | P0 | 📋 |
| 1.7 | 在 Dify 调试面板中用真实题目图片验证全链路输出质量 | P0 | 📋 |
